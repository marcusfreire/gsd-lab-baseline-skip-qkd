Threats and mitigations:
- HIGH: Security docs imply production-safe key handling. Mitigate by stating local-only, simulated key material, no TLS/mTLS/auth in Phase 0, and no production readiness.

- MEDIUM: Future logs expose raw simulated key material or namespace secrets. Mitigate by requiring future implementation to redact `key`, `key_material`, and `SKIP_KEY_ID_NAMESPACE_SECRET`.
- MEDIUM: Entropy language overstates the mock. Mitigate by documenting that entropy is simulated and contract-level only until implementation tests exist.

Blockers: HIGH threats are mitigated through explicit non-production and no-runtime-logic acceptance criteria.
